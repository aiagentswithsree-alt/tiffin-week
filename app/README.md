# Tiffin Week

Weekly meal and tiffin planner. Configure routines once, plan each week, get a
shopping list, a prep plan and printable sheets.

- `CLAUDE.md` — the domain model and the rules that are easy to break
- `BUILD-ORDER.md` — what is built, what is next

## Run

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # tsc --noEmit
npm run build      # production build + service worker
npm run preview
```

React 19 · TypeScript · Vite · Tailwind v4 · react-router · installable PWA.
